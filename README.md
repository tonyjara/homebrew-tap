# tonyjara/homebrew-tap

Homebrew casks for my macOS apps.

```sh
brew install --cask tonyjara/tap/tile-bandit
```

## Tile Bandit

A keyboard-driven workspace switcher that lives in the menu bar —
workspaces as groups of apps, grouped in turn by display profile, with grid
tiling and per-keyboard key modifications.
[Source and docs](https://github.com/tonyjara/tile-bandit).
